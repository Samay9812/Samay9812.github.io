The portfolio Resume buttons already point to `resume/`.

## Put your local HTML résumé online
1. Open the `resume` folder in this package.
2. Delete the placeholder `resume/index.html`.
3. Copy your existing résumé HTML file into `resume/`.
4. Rename it exactly `index.html`.
5. If the résumé uses separate CSS, JavaScript, images or assets, copy those into `resume/` too and preserve their relative paths.

## Publish
1. Create/use the GitHub repository `Samay9812.github.io`.
2. Upload the contents of this package to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)`.
5. Save.

Every future change to `resume/index.html` will appear at the same résumé URL after GitHub Pages redeploys.
